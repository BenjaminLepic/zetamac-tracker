Setup & data

In Chrome or Edge, open chrome://extensions or edge://extensions, turn on Developer mode, choose Load unpacked, and select the zetamac-tracker folder. Then reload any open Zetamac tab.

The extension’s toolbar button opens this dashboard. A small Training log panel appears on Zetamac; expand it to set optional conditions. Each game records automatically.

Only keys typed in Zetamac’s answer field are recorded, along with questions, input changes, correctness confirmed by the game, timings and conditions. Paste and input-method edits appear as input changes. The extension makes no network requests.

Records stay in this browser profile. Export a JSON backup regularly: removing the extension or clearing its storage can delete them. An HTML preview uses separate browser storage and cannot record games. Import merges by session ID; matching IDs are replaced.

Your 16 original scores are dated 26 October 2024 in the order supplied. All have no meeting; only session 12 has glasses. Historical scores have no question or keystroke data, and no invented time of day.

If you reload or close a game, its checkpoint stays in history as partial. A game joined after it started records only what the extension observes. Existing sessions remain labelled with their actual settings.
